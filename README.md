# Joan of Arc

A 2D Unity game inspired by **Metroidvania/Castlevania-style** exploration, featuring an integrated inventory system and procedural map generation.

##  Overview

**Joan of Arc** is a side-scrolling action-adventure project built in Unity.  
The game focuses on classic Metroidvania gameplay: exploration, progression, and combat in a dynamic world.

##  Features

- **Metroidvania-style 2D Gameplay**
  - Side-scrolling exploration
  - Action-focused combat
  - Ability-driven progression

- **Built-in Inventory System**
  - Item collection and management
  - Equipment and resource organization
  - Expandable UI structure for future item types

- **Procedural Map Generation**
  - Randomized map layout generation
  - Improved replayability
  - Modular room/section structure for flexible level design

##  Tech Stack

- **Engine:** Unity (2D)
- **Main Language:** C#
